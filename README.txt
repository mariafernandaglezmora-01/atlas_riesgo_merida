PORTAFOLIO GEOESPACIAL - ZONA METROPOLITANA DE MÉRIDA

Contenido:
1) index.html
   Página HTML tipo portafolio técnico con galería de mapas y narrativa profesional.

2) mapa_interactivo/index.html
   Prototipo de mapa interactivo en Leaflet con control de capas.

3) assets/
   Imágenes de mapas estáticos.

4) mapa_interactivo/data/
   Carpeta preparada para insertar GeoJSON reales.

Cómo usar:
- Abrir index.html en el navegador.
- Para publicar: subir la carpeta completa a GitHub Pages, Netlify o cualquier hosting estático.
- Para activar capas reales en el mapa interactivo, exportar desde QGIS a GeoJSON y nombrar los archivos:
  limite_zmm.geojson
  hidrometeorologico.geojson
  geologico.geojson
  quimico.geojson
  agua_subterranea.geojson
  recarga.geojson

Recomendación:
No publicar capas editables, bases institucionales ni información sensible. Usar versiones generalizadas o derivadas.
